# CogniWeave AI

AI-powered goal planning system for students.

## Features
- Generate personalized roadmap
- Task generation from roadmap
- Resource recommendation
- Progress tracking
- Voice input (local only)

## Tech Stack
- Python
- Streamlit
- Groq API (LLM)
- JSON (memory storage)

## Run Project

```bash
pip install -r requirements.txt
streamlit run app.py
